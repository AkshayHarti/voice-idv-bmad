Accessibility shifts the picture: not shippable as specified. The confirm card — the centerpiece of this round — is an eyesight gate smuggled into a product whose founding promise is screen-unread completion. The spines never arbitrate browser TTS against screen-reader announcements, never say where focus goes when DOM nodes dock and retire mid-run, and let variation rotation erode the predictability assistive-technology users depend on. Accessibility review — not shippable as specified

review-accessibility.md

The confirm card is an eyesight gate smuggled into a product whose founding promise is screen-unread completion. The spines loudly declare "a blind keep/retake with no image is a bug" while shipping the exact inverse bug: a blind user for whom the image is nothing gets no spoken quality description, no non-visual review path, and no defined alt semantics. The Accessibility Floor reads as if the confirm card was designed first and the floor was never re-checked against it. 2 critical, 5 high, 7 medium (1 invalidated in synthesis), 4 low.

critical

Confirm card is unreviewable non-visually

Confirm card row; Choreography; Accessibility Floor
A screen-unread user is asked to Keep/Retake an image they cannot inspect, with no spoken quality description — contradicting the founding requirement.
Fix: mandatory spoken + text quality verdict before the keep/retake question ("Front captured: sharp, all four corners visible, no glare. Keep it, or retake?"), derived from coaching telemetry. A keep/retake with no non-visual quality statement is a bug, same weight as the blind-keep bug.
critical

No TTS / screen-reader arbitration

Voice and Tone; Accessibility Floor SR row
Browser synthesis speaks the line while aria-live regions announce the same or competing updates — SR users hear doubled or overlapping speech with no stated strategy.
Fix: one coherent policy: the spoken-line text twin IS the live region (single source), TTS and SR never fed duplicate strings, plus an "SR detected → suppress self-voicing TTS" rule or explicit toggle. Test with VoiceOver + TalkBack with TTS on.
high

Captured-image alt semantics unspecified

DESIGN.md Confirm card; EXPERIENCE.md Confirm card row
Decorative alt="" with the caption carrying meaning, or informative alt carrying quality state — the spines say neither, inviting double-announcement or a silent image.
Fix: image alt="" (decorative) + a real caption element holding the quality verdict; or informative alt ONLY if no visible caption duplicates it. Never a filename/framestamp as alt.
high

Live-region politeness for the confirm card unspecified

Accessibility Floor; Spoken line row
A blocking question with a retire-on-answer lifecycle gets no level, and its arrival races the per-Turn spoken-line update.
Fix: assertive (or role="alertdialog" semantics) for confirm-card arrival; document ordering vs the spoken-line update so SR users never hear the question before the quality verdict.
high

Focus management across docking / appear / retire unspecified

Capture frame + Coach card + Confirm card rows; Floor focus order
Frame node moves, coach cards replace, confirm card appears then vanishes — each can drop focus to <body>, and "focus order follows reading order" is contradicted by reordered DOM.
Fix: focus moves to the confirm card heading (or Keep button) on appearance; on keep/retake focus returns to a named target; docking never moves the focused element; retiring a focused node moves focus before removal. Test keyboard-only, SR off.
high

Keep/Retake accessible names lack stage context

Confirm card row; Interaction Primitives
The same bare "Keep" / "Retake" repeats across all four stages — an unlabeled choice out of context for SR and voice-control users.
Fix: accessible names carry the capture ("Keep document front" / "Retake document front"); visible text may stay short.
high

Variation rotation breaks the predictability AT users rely on

Variation policy; Inspiration
N phrasings for one meaning: unsearchable transcript, no stable phrase for voice-control/switch users to learn. Recognition tolerance fixes input but the spines celebrate unpredictable output.
Fix: exempt functional prompts (consent, keep/retake, abort) from rotation — fixed wording there — cap rotation to coaching color; meaning-identical lines share one transcript tag so SR search still works.
medium

Near-miss resolution has no confirmation echo

Interaction Primitives recognition-tolerant
"kep it" resolves to Keep, but the resolution is never announced — a mis-resolved utterance silently acts. Transcript rule doesn't say whether heard-form, resolved-form, or both are recorded.
Fix: always echo the resolution in spoken twin + text ("Keeping the front."); record heard → resolved in the transcript; low-confidence near-misses re-ask instead of resolving.
medium

Reduced-motion docking unspecified

DESIGN.md Capture frame; Floor Reduced motion row
Docking "animates opacity/position" and "scrolls into view," but reduced-motion rules cover only glow/flash/transitions — smooth scroll on every stage is a vestibular hit the Floor forgot.
Fix: under prefers-reduced-motion, docking is instant (no smooth scroll, no animation); state change still announced via live region + haptic.
info

Confirm-card mock verification checklist (finding invalidated — mock exists)

.working/confirm-card-mock.html
The reviewer could not see the mock; synthesis confirmed it exists. Its checklist still applies.
Fix: verify: image alt per this review, one assertive arrival announcement, focus-into-card on appear with focus-restore on retire, context-carrying button names, ≥44pt targets with ≥8px gaps, full keyboard operability.
medium

10s silence re-ask can fire while a screen reader is still announcing

State Patterns Listening row
SR output takes longer than TTS; neither the timeout nor the re-ask accounts for SR latency.
Fix: extend/suppress the silence timer while SR announcements are pending where detectable; at minimum the re-ask must not interrupt an in-progress announcement and must itself be polite-queued.
medium

Coach-card diagram slot has no text-equivalent rule

Coach card rows (both spines)
The spatial diagram is exactly the image-only instruction a screen-unread user cannot use, and the Generated panel text-equivalent rule doesn't cover coach cards.
Fix: every diagram ships with a text twin at least as specific as the visual — or the slot is decorative-only by contract and the imperative alone must suffice.
medium

Tap-to-mute can kill the founding channel with no caption backstop

Voice orb row; Captions row
Muting silences speech; the spines never say a muted run still renders text twins (nothing is technically "spoken") — mute + screen-unread is a dead end.
Fix: mute changes audio output only — text twins and live-region announcements continue unchanged; mute state itself is announced and captioned ("Muted. Captions continue.").
medium

Lock signal may be color-only in the static visual

DESIGN.md Capture frame; State Patterns Capturing row
Guides flip blue→green with a flash, but no shape/label change is specified — hue is the only visual delta for low-vision and colorblind users.
Fix: pair the color change with a shape or label change (check-ticks, capturing… → locked); keep the spoken + haptic lock signal unconditional.
low

Pause-shaping commas leak into SR/braille twins

Voice and Tone Speech shaping
TTS-tuned commas will be honored or stumbled over by screen readers and braille displays reading the same text twin.
Fix: verify with at least one SR + braille pass that shaped lines read cleanly; allow the text twin to differ in punctuation from the TTS string if SR testing demands it.
low

Barge-in marking has no announcement rule

Interaction Primitives; Transcript turn row
Interruption "stops synthesis immediately and the partial line is marked" — marked how, and announced or silently visual?
Fix: a polite live-region note ("Interrupted.") plus a transcript marker with an accessible label, not a color/tick-only cue.
low

Tap-target spacing and orb size underspecified

Accessibility Floor; DESIGN.md Voice orb
"≥44pt" with no inter-target gap; the orb mute toggle has no size at all; the docked Keep/Retake pair is exactly where cramped targets happen.
Fix: minimum 8px gaps between Keep/Retake and the input row, orb ≥44pt, documented accessible path for the long-press function.
low

Confirm-card image has no transcript standing

Transcript turn row; Confirm card retire rule
The transcript is "the accessible record," but the confirm step may vanish with the retired card.
Fix: log one transcript turn per confirm step — capture name, quality verdict, decision — so the record survives the card's retirement.
